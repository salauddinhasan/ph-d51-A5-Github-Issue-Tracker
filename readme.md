

1. Difference between var, let, and const

var: is function-scoped, can be redeclared and reassigned.

let: is block-scoped, cannot be redeclared but can be reassigned.

const: is block-scoped, cannot be redeclared or reassigned.



2. Spread Operator ...

Used to expand or copy arrays and objects.

Useful for merging arrays or objects, or creating shallow copies.



3. Difference between map(), filter(), and forEach()

map() – transforms every element and returns a new array.

filter() – returns a new array with elements that pass a condition.

forEach() – iterates over elements, does not return a new array.


4. Arrow Function

Short syntax for writing functions.

Inherits this from the surrounding scope.


5.Template Literals

Strings enclosed with backticks `.

Supports dynamic values with ${variable}.
